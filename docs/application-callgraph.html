04 · DELIVER

Derivative → R2

Asset diproses menjadi WebP yang cukup ringan dengan kualitas baik, lalu disajikan dari domain media production.

Production tidak memakai source URL fallback. Jika asset belum tersedia, status harus jelas dan tidak diam-diam mengarah ke domain lokal.

06 · Contract notes

Guardrails yang harus tetap benar

01

Guest checkout tetap valid

Pelanggan tidak wajib membuat akun untuk membuat order. Nomor order dan status lookup menjadi pegangan setelah submit.

02

Snapshot melindungi histori

Nama, harga, varian, dan detail order disimpan sebagai snapshot agar perubahan katalog tidak mengubah transaksi lama.

03

WhatsApp bukan source of truth

WhatsApp membantu komunikasi. Database order, payment, dan shipping tetap menjadi sumber kebenaran.

04

R2 production-only

Konfigurasi disk dan public URL production harus eksplisit. Jangan fallback ke URL source atau filesystem lokal saat live.

05

Migration forward-only

Jangan reset database aktif. Verifikasi memakai SQLite testing atau database testing terpisah.

06

Status harus manusiawi

Status teknis dipetakan ke label yang pelanggan pahami, dengan empty, error, loading, dan stale states yang terlihat.
