# Brand Asset Requirements

## Logo resmi (aktif)

- `light-logo.png` — wordmark untuk latar terang (header storefront, footer, auth).
- `dark-logo.png` — wordmark untuk latar gelap (sidebar admin).
- Runtime: `/images/brand/light-logo.png`, `/images/brand/dark-logo.png`
- Governance copy: `frontend/brand/assets/light-logo.png`, `frontend/brand/assets/dark-logo.png`
- Sumber: `D:\data_website\BRAND KIT\`

## Photography yang dibutuhkan

- Hero homepage: 1600x1200 atau lebih besar, fokus pada produk terpasang.
- Category: rasio 4:3 untuk Jendela, Pintu, dan Bouven.
- Hasil pemasangan: rasio 3:2 atau 4:3 dengan lokasi dan izin penggunaan.
- Hindari teks yang tertanam di dalam gambar.

## Delivery

- SVG untuk logo vektor jika tersedia; PNG wordmark saat ini dipakai di runtime.
- WebP/AVIF untuk foto final, dengan JPEG/PNG source bila diperlukan.
- Nama file lowercase-kebab-case.
- Catat pemilik hak, sumber, tanggal, dan izin penggunaan.
