# Page Blueprints

## Public shell

`Announcement -> Header -> Main -> Footer -> Mobile bottom navigation`

Header desktop berisi wordmark, primary navigation, search, cart, dan order access dalam satu baris.
Mobile memindahkan empat tujuan utama ke bottom navigation dan link sekunder ke menu sheet.

## Home

1. Asymmetric split hero dengan promo/CMS media.
2. Model finder berbasis `modelCards`.
3. Featured products dengan grid ritmis.
4. Popular products sebagai horizontal snap rail di mobile.
5. Cara belanja ringkas.
6. Bantuan menuju review, FAQ, dan order status.

Hero hanya memakai headline, supporting copy, maksimal dua CTA, dan visual nyata.

## Model hub

Intro singkat, filter design, lalu model cards berdasarkan category-model pair. Model card
menjelaskan kategori dan model tanpa meniru product card.

## Catalog and search

Desktop: filter rail + result header + product grid. Mobile: result header + filter/sort sheet +
dua-column grid bila ruang cukup. Active filters dapat dihapus satu per satu atau reset seluruhnya.

## Product detail

Desktop: media gallery 7/12 dan configurator 5/12. Mobile: media, title/price, variant selector,
primary action, lalu detail. Specs, reviews, dan related products berada setelah decision area.

## Cart and checkout

Cart memakai line-item list dan sticky summary hanya pada desktop. Checkout memakai dua tahap
yang terlihat jelas: detail pengiriman, lalu pembayaran dan konfirmasi.

## Order confirmation and status

Confirmation menonjolkan nomor pesanan, total, payment method, dan next action. Status lookup
memakai form ringkas. Hasil memakai timeline yang tetap dapat dipahami tanpa warna.

## CMS and reviews

CMS memakai reading layout semantik dengan heading yang berasal dari konten. Reviews memakai
varied masonry-like grid hanya jika panjang quote mendukung; mobile selalu single column.

## Admin

Desktop: sidebar tetap + top utility + content canvas. Mobile: sidebar menjadi sheet.

- Dashboard: priority strip, KPI, pipeline, recent orders.
- Resource index: title/actions, query controls, table/cards, pagination.
- Resource show: identity header, facts, related sections, workflow actions.
- Forms: satu column reading width; grouped fields; sticky action bar hanya jika membantu.
